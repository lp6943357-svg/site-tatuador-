# Carvalho Tattoo Studio — demonstração

Site estático demonstrativo para apresentar uma proposta de presença digital ao Carvalho Tattoo Studio, em Belo Horizonte.

## Recursos
- HTML, CSS e JavaScript sem etapa de build.
- Layout responsivo.
- GSAP + ScrollTrigger para animações de entrada e parallax.
- Navegação móvel e links para orçamento via WhatsApp.
- Respeita a preferência `prefers-reduced-motion`.

## Antes de apresentar
- Confirmar com o estúdio o número de WhatsApp, localização e demais informações.
- Substituir as imagens ilustrativas por fotos autorizadas dos trabalhos reais.
- Esta é uma proposta independente; não representa um site oficial nem indica parceria ou aprovação do estabelecimento.
